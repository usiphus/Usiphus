# Usiphus / Clinical Case Flashcards — Historical Project Archive

This directory contains historical source snapshots, roadmaps, release ZIP/PATCH/BUNDLE artifacts, and the V6 Usiphus script. The active V7 → V8 → V9 standalone implementations remain at the repository root.

## Version identification and provenance

- **V1–V2:** no individually labelled V1/V2 archive or source tree was found. Generic early archives and pasted source-text files are preserved as unclassified legacy material; they are not relabelled.
- **V3:** the explicitly labelled V3.0 source snapshot is unpacked under `source-snapshots/v3.0/`; the original ZIP is also preserved in `original-artifacts/` and `v1-v8-package/historical_archives/`.
- **V4–V8:** roadmap documents are preserved under `roadmaps/`. The V1–V8 combined package includes a `current_v8/` source snapshot, tests, schema, and documentation.
- **V5 implementation snapshot:** the source, tests, schemas, docs, and workflows are preserved under `source-snapshots/v5-implementation/`.
- **V6:** `versions/usiphus_v6.py` is the standalone V6 Usiphus script.
- **V7–V9:** the active standalone implementations are at repository root. V8 remains sequenced after V7 and before V9.

## Original artifacts

`original-artifacts/` preserves the supplied ZIP, PATCH, and BUNDLE files byte-for-byte. Byte-identical duplicate uploads are included once. The combined package's original nested archives are also retained in `v1-v8-package/historical_archives/`.

## Important distinction

The archived `current_v8/` codebase and the later standalone `usiphus_v8.py` are separate historical deliverables. Both are retained under their original lineage/context; neither is silently substituted for the other.

No missing V1 or V2 code has been fabricated, and no roadmap item is represented as implemented solely because it appears in a roadmap.
