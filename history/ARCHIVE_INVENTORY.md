# Historical archive inventory

The active standalone Usiphus sequence is V7 → V8 → V9 at the repository root. This folder restores the V6 standalone script and preserves the historical V4–V8 roadmaps.

## Version provenance
- V1–V2: the source package manifest reports that no individually labelled V1/V2 archive or source tree was found. Generic early archives and pasted source-text files must remain unclassified.
- V3: an explicitly labelled V3.0 ZIP exists in the user's source archive; it is not reconstructed here as a separate release.
- V4–V8: roadmap files are included. Separate historical source bundles exist in the user's archive collection.
- V6: standalone script included at `versions/usiphus_v6.py`.
- V7–V9: current standalone implementations are at repository root.

## Historical source packages not represented as extracted files here
The source collection contains ZIP, PATCH, and BUNDLE distributions for the V1–V8 combined package, V3.0, V5 implementation, V5 guideline update, V5–V6 feature work, V4–V8 roadmaps, V7 pre-V8, and V8 roadmap audit. These binary archive artifacts have not been silently renamed or treated as verified source versions.

## Safety and accuracy
Roadmaps document plans and status at their own snapshot date; they do not prove that every listed feature was implemented. The V6 script's own documentation states that it performs structural/educational validation, not medical factuality or clinical safety review. Clinical content requires qualified review against current authoritative sources.
