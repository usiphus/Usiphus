# Ophthalmology evidence packet library

This directory maps all 52 topics in the example ophthalmology curriculum to evidence curation work.

- Five existing files are **candidate-source packets** with bibliographic candidates and curator prompts. They remain unreviewed and ineligible.
- 47 new per-topic files are **discovery plans only**. Each contains three objective-specific PubMed, Europe PMC and Google Scholar discovery links, preferred source families and a curation checklist. They contain no sources or snippets.
- See `INDEX.json` for the full inventory.
- **No packet is faculty-approved, rights-cleared, or clinically validated.** The new worklists intentionally fail generator evidence preflight until actual sources are selected, full texts reviewed, rights verified, exact-locator snippets curated and objective mappings reviewed by qualified faculty.

## Curation sequence

1. Start with the topic's objective-specific query links.
2. Prefer current professional guidance for recommendations, systematic reviews for synthesis, and primary studies for specific evidence questions.
3. Check source currency, jurisdiction, methods, conflicts, full-text access and article-level reuse terms.
4. Add only independently authored evidence notes or legally reusable short excerpts with exact locators.
5. Map each snippet to the exact objective ID and obtain qualified ophthalmology faculty review.
6. Update review/access/rights metadata only after the corresponding checks are actually completed.

Anki decks, DoctorDE challenges and public exam-preparation pages are discovery and exam-practice signals only. Do not copy protected questions or treat these resources as clinical evidence.
