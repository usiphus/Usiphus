# V19 Faculty Pilot Protocol

1. Select one specialty and a small set of learning objectives.
2. Faculty create a blueprint before drafting questions or stations.
3. Draft MCQs with focused lead-ins, homogeneous options, one best answer, answer and distractor rationales, evidence links and version metadata.
4. Draft OSCE stations with candidate and role-player briefs, setup, timing, checklist, critical actions, global rating scale and rubric.
5. Use only original/licensed challenge cases; verify image rights, provenance, consent/de-identification and accessibility.
6. Review every automated flag. Record accepted/rejected/deferred disposition outside the automated tool until a governed decision workflow is specified.
7. Conduct faculty usability review and, if institutionally approved, a small supervised pilot using minimized data.
8. Report defects, unresolved issues, item versions, cohort size/missingness and user feedback. Do not infer psychometric quality from proportion-correct alone.
9. Approve release only through the existing V16 governed release workflow after faculty sign-off.

Exit criteria: all released artifacts have human approval and provenance; no unresolved rights/privacy/accessibility blockers; traceable versions; documented withdrawal and correction process.
